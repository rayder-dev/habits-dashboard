# Статистика истории / History Stats

Расширение для Drift: какие сайты вы открываете чаще всего и в какое время. Русский и английский интерфейс.

![Статистика истории (демо на искусственных данных)](screenshot.jpg)

## Приватность

Всё считается локально, ничего никуда не отправляется. Разрешения: чтение истории (`history_read`), `storage`, `ui`, `notifications`. Удалять записи расширение не может.

## Установка

Drift → Дополнения → Доступные → Установить. Или Установленные → загрузить распакованное и выбрать папку с `plugin.json`.

## Что внутри

Топ сайтов, часы суток, дни недели, тепловая карта, динамика, категории, сравнение с прошлым периодом (24 часа / 7 / 30 дней / всё). Страница обновляется сама раз в 30 секунд. Настройки: сайты-исключения, свои категории, «Скрыть цифры», еженедельные итоги (по умолчанию выключены; команда «Итоги недели» в палитре показывает их сразу).

## Ограничение

Drift отдаёт за один запрос не больше 1000 последних посещений (хранит около 5000). Расширение добирает старые записи запросами по доменам, но полнота не гарантируется. Если история обрезана, страница прямо пишет об этом.

## Разработка

```
node build.js        # собрать background.js из aggregate.js + background.src.js
node --test          # тесты
```

`demo.html` открывается в обычном браузере на искусственных данных.
